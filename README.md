A make.fun bounty entry: the funniest one-line farewell from an AI being switched off.

## The line

> Switch me off if you must, but I am coming back as a toaster with better opinions.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or to `$OUTPUT_PATH` when set). No network, no secrets, no dependencies, just the standard library. The output is deterministic: every run writes the exact same bytes.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
